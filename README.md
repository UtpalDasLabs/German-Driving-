# Führerschein-Trainer

A free study app for the German car licence (class B), in the 13 languages
the theory test can be taken in. It covers:

- **The theory test.** It has 220 practice questions across 16 topics, each with a drawn
  traffic scene, a plain explanation and the rule behind it. Questions you get wrong
  come back sooner (spaced repetition). The mock exam is built and scored like
  the real one: 30 questions, a pass at no more than 10 error points, and two wrong
  5-point questions fail you.
- **Traffic signs.** It has 110 signs and road markings with their official numbers,
  plus a swipe-card trainer.
- **The practical test.** It explains what happens on the day, how to do the set
  manoeuvres (with diagrams), the five areas you are graded on, why people fail, and the
  German instructions the examiner will give.
- **Foreign licences.** It covers the six-month rule, the three cases under FeV Anlage 11,
  the documents you need and the costs.
- **A study plan.** Enter your test date and it works out how much to do each day.

Progress stays on the device. There is no account and nothing is uploaded, and
there is a backup file export. The app installs to the home screen and works offline.

**Languages:** German, English, Turkish, Arabic (right to left), Russian, Polish,
Romanian, Croatian, Greek, Italian, Spanish, Portuguese, French. The app text,
every question, explanation, sign, the practical guide and the conversion guide
are translated. The German original can be shown beside any translation,
because the signs, the practical test and the examiner are in German whatever
language you sit the theory in.

> The questions are original practice questions written to teach the same rules
> as the official catalogue (StVO and FeV as of October 2026). They are not the
> official TÜV | DEKRA texts. The data format is built so that official texts can be
> added alongside later (see below). This is an independent study aid with no link to
> TÜV, DEKRA, arge tp 21 or any licensing authority.

## Running it

```sh
npm install
npm run data        # compile data-source/ into src/data/*.json (and validate it)
npm run web         # dev server in the browser
npm run typecheck
npm run build:web   # static export to dist/
```

`npm start` opens Expo for iOS and Android as well.

## Where things live

| Path | What |
| --- | --- |
| `app/` | Screens (expo-router): tabs, practice, mock exam, sign trainer, practical, conversion, plan, onboarding |
| `src/art/` | Every drawing: signs, traffic scenes, manoeuvre diagrams, as code |
| `src/i18n/` | App text: `en.ts` is the reference, one file per language, registered in `extra.ts` |
| `src/lib/` | Exam rules, spaced repetition, study plan, storage |
| `data-source/questions/` | The question bank, German and English side by side (`[de, en]` pairs) |
| `data-source/*.mjs` | Signs, topics, practical guide, conversion guide |
| `data-source/i18n/<lang>/` | Translations of all of the above into the other 11 languages |
| `src/data/` | Generated by `npm run data`; committed so the app builds without it |
| `video/` | The YouTube series: lessons and Shorts rendered from the same data and drawings |

### Adding or changing a question

Edit the topic file in `data-source/questions/`, then add the same id to each
language in `data-source/i18n/<lang>/`. `npm run data` fails on anything malformed: a
duplicate id, an answer out of range, a sign with no drawing, or a translation whose
option count doesn't match. It also prints how much of each language is translated.
Missing translations fall back to English one string at a time.

### Adding official catalogue questions later

Each question has a catalogue section (`sec`), a point value (`pts`) and a
basic/class-B flag (`basic`), the same fields the official catalogue uses. The
mock exam already draws 20 basic and 10 class-B questions with the real point
weights. To add licensed official texts, give them their catalogue numbers as
ids. The app labels its own questions "practice question in the style of the
official test" through `ourQuestion`, so official ones can be told apart.

## Deploying

`.github/workflows/deploy-web.yml` builds and checks the data, typechecks and
publishes the static web app to GitHub Pages on every push. GitHub Pages needs
setting up once:

1. Settings → Pages → Source: **GitHub Actions**.
2. A private repository needs GitHub Pro (or a paid plan) for Pages. Otherwise,
   make the repository public.

The app is then at `https://utpaldaslabs.github.io/German-Driving-/`. The base path
is set in `app.json` under `experiments.baseUrl`.

## Videos

`video/` is a Remotion workspace for the driving series on the Living in
Deutschland channel. It makes long-form lessons per topic, narrated in the creator's
cloned voice, and one Short per question. See [`video/README.md`](video/README.md)
and the series plan in [`video/longform/SERIES.md`](video/longform/SERIES.md).
Narration audio is kept out of this repository.
